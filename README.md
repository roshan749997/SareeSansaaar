## 📌 Overview

**SareeSansaaar** is a dedicated online retail portal for handcrafted traditional sarees and ethnic wear. It provides a smooth shopping experience with product collections, customer carts, and secure digital checkout via Razorpay.

---

## ✨ Features

- 💳 **Integrated Payment Processing:** Full payment lifecycle support with Razorpay hash generation, callback verification, and order confirmation.
- 📦 **Catalog & Inventory:** Structured filtering by fabric, design, and occasion.
- 📱 **Responsive Design:** Optimized for mobile shoppers and high-resolution product galleries.

---

## 🚀 Setup

### Backend


### Frontend
```bash
cd frontend
```
